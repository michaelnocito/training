# Implementation Practice Labs

Short learning apps designed to guide those in the SAAS Implementation roles.
Actively in development. Fully functional. 

Each lab runs in the browser, with no install or sign-up.

## Labs

- [SaaS Implementation Lab](https://michaelnocito.github.io/training/saas-implementation-lab.html): planning an implementation from kickoff to go-live.
- [Fast-Track Implementation Lab](https://michaelnocito.github.io/training/fast-track-implementation-lab.html): shortening timelines without skipping steps.
- [API Support Tickets](https://michaelnocito.github.io/training/api-support-tickets.html): working through API support scenarios.
- [JSON for Field Mappers](https://michaelnocito.github.io/training/json-for-field-mappers.html): reading JSON and mapping fields between systems.

## Notes

Progress is saved in your browser only. Nothing is collected or sent anywhere.
